🔐 Secure File Encryption System

Project Overview

A Python-based Secure File Encryption System developed using Fernet Cryptography to protect files through encryption and decryption.

This project demonstrates the basic concepts of cryptography and secure file handling using Python.

Features

- File encryption using Fernet symmetric encryption.
- Secure file decryption.
- Key generation for encryption and decryption.
- Password hashing.
- User registration and login functionality.

Technologies Used

- Python
- Cryptography (Fernet)
- Hashlib
- VS Code

How It Works

1. Generate an encryption key.
2. Provide a file as input.
3. Encrypt the file using Fernet.
4. Store the encrypted output.
5. Decrypt the file using the corresponding key.
